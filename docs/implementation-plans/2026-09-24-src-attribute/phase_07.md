### Task 1: README

**Verifies:** None (docs)

**Files:**
- Modify: `README.md`

**Changes:**
- `### Attributes`: add `src` and `crossorigin`.
  - `src` is a stored image URL. The component shows it as-is, never
    fetches it, never puts it in the file input, and never announces
    it with `change`. Setting a non-empty `src` drops a held file, and
    `''` means none.
  - `crossorigin` is forwarded to the preview `<img>` and the
    cropper's `<img>`.
- `### Events`: `change` now carries
  `source:'pick'|'drop'|'crop'|'api'`. `edit` is `{file, src}` and
  `alt` is `{file, src, alt}`, with `file` null for a stored image.
  `error.reason` adds `'crop-failed'`. An `alt` present at parse time
  emits no `alt-change`. In the `#### Typescript` sample, change the
  error comment `ev.detail.reason  // 'not-an-image'` to
  `'not-an-image'|'crop-failed'`, and add `ev.detail.source` to the
  `change` sample.
- `### image-crop` > `#### Attributes`: add `crossorigin`. Note that a
  `src` switch resets the crop until the new image loads.
- `### cropDialog`: add the `crossorigin` option, and note that a URL
  source is cropped to the type its extension implies, falling back
  to JPEG.
- `## API` > `### Methods`:
  - Add `edit()` / `ImageInput.edit(el)`. It returns
    `Promise<File|null>`, resolves after `change` on Save, and gives
    `null` on cancel, under `nocrop`, with no image, or when `edit` is
    canceled. Calling it again while the dialog is open returns the
    same promise.
  - Update `clear()` to say it also removes `src`.
- `### Server rendering`:
  - `html({src, crossorigin})`.
  - `required` now writes `data-required`, and writes `required` only
    when there is no stored image.
  - The client's `setSrc(url)` and `edit()`.
  - The client now emits `error` for `not-an-image` and
    `crop-failed`.
- A new `### Stored images` subsection, placed after `### Events`,
  covering:
  1. Seeding with `<image-input src="/img/cover.png">`.
  2. `src` replacing a picked file (and the Preact caveat: assigning
     `el.src` on every render loses a pick).
  3. An empty `src` means none.
  4. `required` is satisfied by `src`.
  5. A plain form submit sends no file for a stored image, so the
     server keeps what it has. A removed image is not signaled in a
     no-JS submit (out of scope).
  6. CORS: `crossorigin` needs the server to send
     `Access-Control-Allow-Origin` (with `Vary: Origin`, or `ACAO: *`).
     A `crossorigin` preview fails to load without those headers.
     Without `crossorigin`, cropping a cross-origin image fails with
     `error` `crop-failed` (tainted canvas).
  7. Extensionless URLs crop to JPEG.
  8. The pick-then-`edit()` recipe:
     `el.addEventListener('image-input:change', ev => { if (ev.detail.source === 'pick') el.edit() })`.
  9. `alt-change` fires only after connect.

### Task 2: FDR-006 and the index row

**Verifies:** None (docs)

**Files:**
- Create: `docs/fdr/FDR-006-stored-image-source.md`
- Modify: `docs/fdr/INDEX.md` (append a table row)

**Content:** Use FDR-005's structure. Take the substance from
`docs/design-plans/2026-09-24-src-attribute.md`:
- **Header:** `**Status:** Implemented` and `**Last reviewed:**` set to
  the date of the commit.
- **Overview:** Why stored images are needed: editing a record whose
  image already lives at a URL.
- **Behavior:** The state-transition table (set `src`, empty or remove
  `src`, pick/drop/`setImage`/crop, Remove/`clear()`), `required`,
  ALT/Edit/Remove on a stored image, `edit()` semantics, `crop-failed`,
  `change.source`, the seeded-alt rule, and client parity through
  `setSrc`.
- **Design Decisions**, each with its rationale:
  1. Never fetch `src`. A `HEAD` request to learn the type was
     rejected, so extensionless URLs crop to JPEG.
  2. `src` never goes into the file input.
  3. Shared pure helpers in `file.ts` instead of delegating to the
     client or adding a state class.
  4. `crossorigin` is forwarded to both images, so they share one CORS
     cache entry.
  5. Crop type and name are fixed when the dialog opens.
  6. `crop-failed` leaves `edit()` pending.
  7. The `data-required` intent plus `inputRequired`.
  8. Re-setting the same URL still drops a pick.
  9. Reopening `edit()` on the same stored URL after a Cancel keeps
     the previous session's crop rect. `ImageCrop` skips an unchanged
     `src`, so the image is not reloaded. A `setFile` session always
     resets.
- **Related:** FDR-003, FDR-005, ADR-002, and the design plan.
- **Open Questions:** A no-JS "removed" signal. The lost `#file`
  preview on reattach.

INDEX row:

```
| [FDR-006](FDR-006-stored-image-source.md) | Stored image source | Implemented | <date> |
```

### Task 3: Stored-image toggle in the example

**Verifies:** None (example; verified by the build)

**Files:**
- Create: `example/stored.jpg` (copy of `test/cinnamon-roll.jpg`)
- Modify: `example/controls.ts` (new prop and button)
- Modify: `example/index.ts` (import the asset, `onToggleStored`,
  pass it to `Controls`)
- Modify: `example/AGENTS.md` (rule 6: mention the third button)

**Implementation:**
- `cp test/cinnamon-roll.jpg example/stored.jpg`
- `example/index.ts`: `import storedUrl from './stored.jpg'`. In
  `Example`:

  ```ts
  /**
   * Show or hide a stored image by setting `src` on the element --
   * imperatively, never as a vdom prop (rule 1). A stored image is
   * never announced with `change`, and setting one drops any picked
   * file silently, so the page resets its own panel -- as `onClear`
   * does -- rather than waiting to be told.
   */
  const onToggleStored = () => {
      const el = ref.current
      if (!el) return
      el.src = el.src ? null : storedUrl
      State.reset(state)
  }
  ```

  Pass `onToggleStored=${onToggleStored}` to `Controls`.
- `example/controls.ts`: add `onToggleStored:() => void` to
  `ControlsProps`, and add a third button,
  `<button type="button" class="stored" onClick=${onToggleStored}>Stored image</button>`,
  in `.actions`. Check `src/html.ts` so the class name `stored` does
  not collide with a component class. It does not today. Extend the
  doc comment to describe the button.
- `example/AGENTS.md` rule 6: add one sentence saying that the Stored
  image button also calls into the element, by setting `src` through
  the ref, and that it is not a prop.
